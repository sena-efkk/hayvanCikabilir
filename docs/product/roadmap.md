# Hayvan Çıkabilir — Ürün Yol Haritası

## Faz 0 — Ürün Temeli

Amaç: Ne geliştirdiğimizi kesinleştirmek.

Çıktılar:

* Ürün vizyonu
* Hedef kullanıcılar
* Değer önerisi
* MVP kapsamı
* Başarı metrikleri
* Temel ürün ilkeleri
* Ana kullanıcı akışları

Bu fazda production kodu yazılmaz.
