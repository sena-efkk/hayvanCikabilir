# Hayvan Çıkabilir — Ana Kullanıcı Akışları

## 1. Hesap Oluşturma

Uygulamayı aç
→ Register
→ Bilgileri gir
→ Hesap oluştur
→ Ana uygulamaya geç

## 2. Hayvan Profili Oluşturma

Profile
→ Hayvanlarım
→ Yeni Hayvan
→ Temel bilgileri gir
→ Profil fotoğrafı ekle
→ Kaydet
→ Animal Profile

## 3. Kendi Hayvanı Adına Paylaşım

Create Post
→ Kendi Hayvanım
→ Hayvan seç
→ Fotoğraf seç
→ Açıklama yaz
→ Ön izleme
→ Paylaş
→ Gönderi Feed içerisinde görünür

Kullanıcının hayvanı yoksa hayvan oluşturma akışına yönlendirilmelidir.

## 4. Sokakta Karşılaşılan Hayvanı Paylaşma

Create Post
→ Karşılaştığım Hayvan
→ Fotoğraf seç
→ Hayvan hakkında temel bilgi gir
→ Kısa hikâye yaz
→ İsteğe bağlı yaklaşık konum ekle
→ Ön izleme
→ Paylaş

Bu akışta kalıcı Animal profili oluşturmak zorunlu değildir.

## 5. Gönderiyle Etkileşim

Feed
→ Gönderiyi gör
→ Beğen

veya:

Feed
→ Gönderi
→ Comments
→ Yorum yaz
→ Gönder

## 6. Hayvanı Keşfetme

Feed / Explore
→ Animal Profile
→ Hayvan bilgilerini gör
→ Geçmiş gönderilerini gör

İleride:

Animal Profile
→ Follow

eklenebilir.

## 7. İçerik Raporlama

Post Detail
→ More Actions
→ Report
→ Rapor nedeni seç
→ Gönder

Raporlama kullanıcıyı gereksiz adımlarla zorlamamalıdır.

## Genel Akış İlkesi

Temel kullanıcı eylemleri mümkün olduğunca kısa olmalıdır.

Özellikle paylaşım oluşturma akışının gereksiz ekranlarla uzatılmaması gerekir.

Her akış ayrıca:

* Loading
* Empty
* Error
* Success

durumlarını feature specification aşamasında tanımlamalıdır.
